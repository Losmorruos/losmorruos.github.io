ACTUALIZAR LA CABECERA DE LOS MORRUOS

La página ya utiliza el archivo cabecera-los-morruos.jpg en index.html.
Para poner la nueva imagen sin recortarla:
1. En GitHub abre el repositorio Losmorruos/losmorruos.github.io.
2. Abre el archivo cabecera-los-morruos.jpg y elige eliminar/reemplazarlo, o sube este archivo con exactamente ese nombre sobrescribiendo el anterior.
3. Haz commit en la rama main.
4. Espera a que GitHub Pages publique y recarga la web.
