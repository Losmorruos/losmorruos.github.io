LOS MORRUOS — PROYECTO COMPLETO SEO + PWA

Este ZIP contiene la aplicación completa y los archivos SEO integrados.

INCLUYE:
- index.html modificado con SEO, Open Graph, Twitter Cards y datos estructurados
- manifest.json actualizado para PWA
- robots.txt
- sitemap.xml
- todos los archivos de la versión completa anterior (data.json, imágenes, service worker, OneSignal, etc.)

PUBLICACIÓN:
1. Descarga y descomprime este ZIP.
2. Sube TODOS los archivos a la raíz del repositorio de GitHub Pages, sustituyendo los anteriores cuando corresponda.
3. Espera a que GitHub Pages publique los cambios.
4. Comprueba https://losmorruos.github.io/clublosmorruos.com/
5. Después registra la URL en Google Search Console y envía sitemap.xml.

NOTA: no contiene una etiqueta google-site-verification porque Google genera una diferente para cada propietario. Esa etiqueta se añadirá cuando hagas la verificación en Search Console.
